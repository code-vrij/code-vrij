# achtergrond/

Waarom deze repository bestaat.

## De korte versie

Werken met een AI coding agent gaat zelden in één keer goed. Wat de eerste opdracht oplevert, klopt niet helemaal, en dan volgt het echte werk: bijsturen. Elke bijstelling is een correctie op een bedoeling die niet scherp genoeg was uitgesproken.

Die correcties zijn waardevol, maar verdwijnen meestal met het project waar ze uit kwamen. Het idee vooraf is te vaag, en het product achteraf laat niet meer zien wat er onderweg is geleerd. Daartussen zit de kennis over hoe je zegt wat je wilt. Dat is wat hier geoogst wordt.

Een agent kan die kennis lezen, praten met de gebruiker over diens situatie, en er iets van bouwen dat past. Daarom staat hier geen code. Wat een agent ermee maakt is van de gebruiker, staat ergens anders en mag weg zodra het niet meer past.
